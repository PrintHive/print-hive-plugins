## Descriptions

**Short description**

Run your 3D-print farm with agents.

**Long description**

Connect ChatGPT, Codex, or Claude to Print Hive for organization-scoped fleet visibility, model and material management, inventory operations, Makes, print-job dispatch, and guarded printer control. OAuth scopes, exact target resolution, confirmations, and human-controlled credential entry protect production equipment.

## Starter prompts

1. Show me the health of my print farm.
2. Find a model file and queue a confirmed print.
3. Review filament inventory and open risks.

## Release notes

Initial public release of the Print Hive agent plugin, including OAuth connection, secure account and printer setup guidance, fleet operations, models and files, materials and inventory, Makes, print queues, and confirmation-gated printer controls.

## Network domains

- `https://api.printhiv3d.com` — MCP, OAuth discovery, authorization, and API operations.
- `https://app.printhiv3d.com` — signup, OAuth consent, printer credential entry, and product deep links.
- `https://printhiv3d.com` — public documentation, support, privacy, and terms.

The plugin does not embed a remote web component and does not require inline frames.
